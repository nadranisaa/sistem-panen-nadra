# Sistem Pencatatan Hasil Panen Digital
Repository ini berisi program sederhana untuk mencatat dan menghitung total hasil panen secara digital menggunakan Python dan Git.
## Deskripsi
Program digunakan untuk menghitung total hasil panen dari beberapa data hasil panen serta menghitung total setelah diberikan diskon.
## Cara Menjalankan
Jalankan file `panen.py` menggunakan Python:
```bash
python panen.py
```
Program akan menampilkan total hasil panen dan total setelah diskon.
